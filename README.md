# 数据库甘特图挂件

把思源数据库作为甘特图直接嵌入文档。配置保存在挂件块的自定义属性中，每个挂件实例可以连接不同数据库、使用不同字段。

## 安装

1. 将整个 `siyuan-gantt-widget` 文件夹复制到 `{工作空间}/data/widgets/`。
2. 在思源“设置 → 集市 → 已下载 → 挂件”中确认挂件可用。
3. 在文档中输入 `/挂件`，选择“数据库甘特图挂件”。

## 配置

1. 点击挂件内部的“设置”。
2. 填写数据库 ID（AV ID）；也兼容数据库块 ID 并自动解析。
3. 点击“读取字段”。
4. 配置标题、开始、结束、完成情况和紧急程度字段。
5. 点击“保存并应用”。

数据库 ID 是数据库的 `data-av-id`。挂件优先按 AV ID 读取；若填写数据库块 ID，也会自动解析并在保存时转换为 AV ID。

## 字段规则

- 标题：块字段或文本字段。
- 开始/结束：日期字段。
- 结束可选择“使用开始字段的日期范围”。
- 完成情况：选择复选框字段；已完成显示为低饱和绿色，未完成显示为低饱和黄色，不显示百分比。
- 紧急程度：选择单选或多选字段；值“一般”“重要”“紧急”分别映射为低饱和绿、橙、红。
- 甘特条颜色只由紧急程度决定，不随完成情况改变。
- 没有开始日期的行不会显示。
- 任务列始终显示全部有开始日期的任务，不因当前可见时间段而隐藏。
- 任务顺序采用数据库活动视图的渲染结果，支持同步多字段排序；若渲染接口不可用，再回退到基础 `itemIds` 顺序。
- 时间轴连续覆盖任务日期并在前后留出缓冲，可横向滚动跨越不同月份。
- 周视图显示连续 7 天，默认将今天固定在第 3 个日期格，日期格式为“周五 24”。
- 月视图显示连续一个月的天数，默认同样将今天固定在第 3 个日期格；仅显示日期数字，日期之间不绘制竖线，周末整列使用灰色底。
- 左右悬浮箭头分别移动上一/下一周或月；“今天”按钮可快速恢复默认定位。
- 今日在当前周期内时使用红色竖线标记。
- 今日竖线位于当天格子的右边界；不显示“今天”文字，当前日期数字使用红色圆形底和白色文字强调。
- 正文与时间轴字号略微增大；设置下拉框使用更紧凑的 12px 字号。
- 左侧任务标题栏固定不随横向滚动，可拖动调整宽度，最窄可缩至 80px。
- 任务列采用紧凑单行布局，不显示标题下方的日期范围。
- 时间轴任务区域不绘制横向分隔线，仅保留日期纵向网格。
- 日期时间轴支持横向滚动；纵向滚动条隐藏。
- 挂件根据工具栏、任务行和设置行的实际内容自动调整高度，并同步思源的 iframe 与外层挂件块。
- 高度更新使用短暂防抖，设置展开、保存收起或数据刷新时不会连续抖动。
- 挂件脚本覆盖思源默认的 iframe 边框，外沿不再显示灰色框线。
- 设置改为工具栏下方的内联配置行，保存后自动收起；窄窗口下自动换行。
- 刷新和设置按钮采用思源系统同款 SVG 轮廓图标、尺寸与悬停样式。

## 数据和安全

- 甘特图只读，不修改数据库。
- 配置通过 `/api/attr/setBlockAttrs` 保存到当前挂件块。
- 字段和值通过 `/api/av/getAttributeView` 读取，显示顺序通过 `/api/av/renderAttributeView` 与数据库活动视图同步。
- 不直接访问或修改 `.sy` 文件。
